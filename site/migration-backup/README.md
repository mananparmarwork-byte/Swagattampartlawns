# Migration backup archive

This folder is reference-only. It contains the original Replit artifact
configuration and the small Express API scaffold that existed in the Replit
workspace before this GitHub Pages export was prepared.

The active static frontend does not import, execute, or depend on anything in
this folder. Do not restore the old server automatically. If a future feature
needs server-side behavior, use the archived code to understand the original
behavior and recreate it using the GitHub Pages + Supabase architecture.

No credentials, passwords, service-role keys, or private keys are stored here.
